agent-scaling · BrowseComp-Plus · gpt-oss-20b · run 1 of 3 · 7–8 October 2026

Seventeen team setups on ten BrowseComp-Plus questions

What was run

The first 10 of the scaling paper’s 100 BrowseComp-Plus questions. Every setup uses gpt-oss-20b, the paper’s search index over 100,195 pages, and the paper’s grader prompt answered by gpt-oss-20b. Each multi-agent setup ran twice: with every agent searching the whole collection, and with the collection split three ways.

SetupHow the agents work togetherHow the team’s answer is formed
Single agentOne agent, 30 model calls.Its own answer.
IndependentThree agents work alone in parallel.All three answers pasted together and graded as one.
CentralizedAn orchestrator plans, then instructs the three agents round by round (up to 5 rounds) from their summaries.The orchestrator writes it from the team’s findings.
DecentralizedThree rounds of debate: after each round every agent reads its peers’ answers and revises.Majority vote over the final answers.
HybridCentralized, plus one round in which the agents read each other’s summaries directly.The orchestrator writes it.
Agent-driven, text / A2A / shared state / all channelsThree peers with no rounds and no leader. They contact each other whenever they choose, through the channels their team has: free-text messages, A2A-style tasks with states and JSON data, a shared key-value store, or all three. Each is asked to agree on who investigates what before searching.Propose, then decide: each agent proposes an answer with its confidence and evidence, which every teammate receives. Once all three have, everyone sees all proposals and gets 8 more calls; one agent submits the team’s answer, and the first submission is final.

The first five rows follow the scaling paper’s released code. Split: each agent can search and open only its own third of the collection, and every agent (and the orchestrator) is told how it is divided. The single agent always searches everything. On 4 of these 10 questions the answer pages sit in only one agent’s third, so on those, the team can answer only if that agent’s finding gets through.
